#
# One entry per line:  path :: text
#   path  a file, a directory prefix ending in "/", a glob (docs/*.md), or *
#         for any file
#   text  what is allowed on the line (matched without regard to case; it is
#         taken out of the line before the check, so a line that also uses
#         another product word still fails). Nothing after "::" allows the
#         whole file or directory.
# Every entry says why. An entry that matches nothing is an error: remove it.
#
