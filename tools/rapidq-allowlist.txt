# Robert (2026-10-24, 2026-10-30): "We don't care about RapidQ, we care about
# RapidR." RapidQ is named in the importer's own texts and, as the compatibility
# page's one line, nowhere else. Anything new that needs the name has to say why
# here; most of it should be rewritten around the behaviour instead ("classic
# names", "a classic compiler").
#
# One entry per line:  path :: text
#   path  a file, a directory prefix ending in "/", a glob (docs/*.md), or *
#   text  what is allowed on the line (matched without regard to case; it is
#         taken out of the line before the check). Nothing after "::" allows
#         the whole file or directory.
# An entry that matches nothing is an error: remove it.
#
# Never needing an entry (tools/check_rapidq_mentions.py's NAMES): the importer's
# command and component (`rapidr import-rapidq`, ImportRapidQ), its menu items
# (Import RapidQ Project or File…, Import RapidQ Folder…, Import a RapidQ
# Program…), the folder examples/rapidq/, links to docs/rapidq-*.md, the include
# file RAPIDQ.INC / RAPIDQ2.INC (an older program writes it in its $INCLUDE line)
# and the ids of file types (RapidR.RapidQSource, text/x-rapidq-basic).
#
# Not scanned at all: source comments, test modules and fixtures, build scripts,
# the legal record (docs/legal/), published history (CHANGELOG.md's versions,
# docs/release-notes/, the extension's CHANGELOG), plans and engineering notes
# (docs/*.md outside docs/manual/), and the guides for contributors
# (CONTRIBUTING.md, COMPILER_MANUAL.md, VSCODE_EXTENSION.md) and the drafts for
# RapidQ's own user groups (ANNOUNCEMENT.md).
