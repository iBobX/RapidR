# Third-party notices: RapidR for VS Code

The extension (MIT, see LICENSE) bundles these JavaScript packages into `dist/extension.js`. Generated by `scripts/notices.js` from package-lock.json; do not edit by hand.

The language server and the debug adapter are part of RapidR itself (`rapidr lsp`, `rapidr dap`), not of this extension: RapidR's own notices come with RapidR (`rapidr notices`).
