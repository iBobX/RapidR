## Findings

1. **The release smoke tests could not work after SEC-24** (the GUI checks of a release build need a signed test-mode
   token). `smoke.sh` and `smoke.ps1` now take `RAPIDR_TEST_MODE` or `~/.rapidr/test-mode.token`; for a VM the token file
   is copied to that user's `.rapidr` folder (it is signed and expires 2027-02-27; it is in both VMs now).
2. `smoke.sh` could not find `p5check.sh` after changing folder (fixed: `HERE`); `p5check.ps1`'s Spanish menu pattern
   assumed a console that decodes UTF-8 (fixed); `smoke.ps1`'s first `-Regress` block had a character Windows
   PowerShell reads as a quote (fixed, and the three Windows scripts are parse-checked in the VM).
3. **Two examples were in neither `tests/examples_run.mjs`'s table nor `examples/README.md`** (`studio/crash_reports.rr`,
   `translations/language_picker.rr`), so the examples' index check failed before it ran anything: both are listed now
   (the first reads a crash folder of its own, `RAPIDR_CRASH_DIR`).
4. **`system_info` (RSystemInfo) test cases assumed the CPU's name is known** (`unknown: nothing here`, `" cores), "`): a
   Linux aarch64 VM has none, so the conformance case and the example failed there. The product says it right
   (`Linux ... on 6 cores, 11 GB of memory`); the two expectations are loosened, run on all three systems.
5. **Windows only, not fixed (a code change after the build):** a missing data file in `RCSV`/`RJSON` says
   `can't read "staff.csv": The system cannot find the file specified.` instead of `there is no file "staff.csv"`
   (`crates/rapidr-value/src/datascience/link.rs`, `unreadable()` matches "no such file" and "not found" only). Small;
   a task is flagged for the next release together with the Windows examples' harness.
6. In the VMs, `PrlJob_GetResult: Invalid argument` retries and `NativeCommandError` lines from rustup's stderr are
   the known Parallels / PowerShell noise (parallels-vms.md); nothing failed because of them.

## What the packages are built from

`dist/2.122.0/prep/commit` is `c1708955`. The code of the packages is that commit's. After it, on this branch: the
release scripts, `tests/` (the examples' table, the system_info cases, the harness' environment options), `examples/README.md`,
the manual's and notes' documents, and the merge of `development` that brought in the RECORD-TUTORIALS lane: its tools/video,
docs and tests, and one **code** change, `crates/rapidr-ui-app/src/demo/app.rs` (34 lines: the demo-mode replay fix). Demo mode is a
development tool behind SEC-24's gate (a development build or the signed token) and not public in Preview 5, so the
packages without that fix behave the same for a user. Rebuilding (prepare.sh, macos.sh, the two VMs, the smoke tests:
about two and a half hours) is only needed if the tag must contain exactly the built code.
