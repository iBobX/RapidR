# RapidR 2.118.0 — Preview

> **This is a Preview.** RapidR Studio and the compilers are ready to try, and
> we want your feedback before the 1.0 launch: what works, what breaks, what's
> missing. Please report it on GitHub Issues. Known gaps are listed below.

RapidR runs and builds RapidQ programs. It targets full compatibility with
RapidQ on all three of its runtimes — the **native compiler** (your program as
a native executable), the **interpreter** (the RapidR Runtime, and standalone
executables that carry it) and the **web** (the same program in a browser) —
and an existing RapidQ program behaves as it does under RapidQ.

RapidR also goes further than RapidQ, without changing what RapidQ programs
do: a data-science stack (data frames, arrays, charts), an AI stack, SQLite and
MySQL, high-DPI screens and accessibility, and more.

RapidR is not a clone of RapidQ. It is an original implementation,
written from the ground up in pure Rust, that is compatible with RapidQ.

## What's new

- **RapidR Studio, the IDE** — desktop (macOS, Windows, Linux) and in the browser:
  - **IntelliSense:** completion as you type and on Ctrl+Space, members after `.`, parameter hints, hover docs, F12 Go to Definition, live problems with quick fixes.
  - **Debugger:** breakpoints (conditional too), step over / into / out, Variables, Watch and Call Stack, values on hover, edit a value while paused, stop at the line of a runtime error.
  - **Form designer:** add forms and modules, every component from the toolbox, the inspector (properties and events), menu and tab-order editors, MDI child windows, multi-form projects; the code it writes stays plain RapidQ-style BASIC.
  - Documents as tabs with a Design | Code switch, split editors, Find in Files, F1 help, Markdown preview.
  - **Build:** native apps (with Rust), interpreted apps (no Rust needed), and **web apps** as a .zip for any web host — also from Studio in the browser.
- **RapidR names:** RButton, RLabel, RForm… everywhere; RapidQ's names (QBUTTON…) still work unchanged. **File > Import RapidQ Project or File…** converts a copy (.bas, .rqw, .rqb, .rq).
- **RapidQ compatibility:** Windows DLL calls (on Windows), Direct3D on the GPU everywhere, console box characters, event order, fonts and dialogs as RapidQ shows them; serial ports for IoT boards (ESP32 tested).
- **New example: CSV Explorer** — drop a CSV, see it in a grid with stats and a live chart.
- New look by default (`$THEME rapidr`, light / dark / high contrast); `$THEME classic` keeps RapidQ's.

Full details: `CHANGELOG.md`.

The SDK includes the runtime. Each install is for you alone and needs no
administrator rights (the `.deb` packages install system-wide).

**Start working right away:** install, open the IDE (Windows: Start menu >
RapidR Studio; macOS: RapidR Studio; Linux: RapidR Studio in your applications), write a
program and press Run. No other software is needed to run programs or to make
standalone executables (`rapidr build prog.bas --interp`). Native builds
(`rapidr build prog.bas`) compile your program with Rust: `rapidr setup`
installs it once, after asking.

**File types:** a `.rrbc` (a compiled RapidR program) runs on a double click;
a `.rr` or `.bas` opens in the IDE, and "Run" (Windows) or "Open With > RapidR
Runtime" (macOS, Linux) runs it. A program downloaded from the internet asks
once before it runs. On macOS and Linux a script that starts with
`#!/usr/bin/env rapidr` runs directly.

## Known issues in this Preview

- Studio on the web runs programs in a frame of at most 880 × 620; a larger program window is cut off there (desktop is fine).
- Studio on the web: a screen reader doesn't announce the inspector's read-only rows as read-only.
- A debugger step can take a little over 100 ms on a heavily loaded computer (about 85 ms normally).
- A few pixels can differ between Studio on the desktop and on the web.
- Not yet: `FormStyle = fsMDIChild`, shaped windows (`SetWindowRgn`), `$UNSAFEMEM` (raw memory for old RapidQ memory helpers), native library calls on macOS/Linux. Windows DLL calls work on Windows only.
