# RapidR 2.121.1 — a hotfix for Preview 4

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

RapidR is a modern BASIC with its own IDE, RapidR Studio. Write a program once
and run it as a **native** executable, a standalone **interpreted** app, or on
the **web**, on Windows, macOS and Linux alike. Everything in
[2.121.0, "Preview 4: Studio, solid"](https://github.com/iBobX/RapidR/releases/tag/v2.121.0)
is here; this release fixes what we found using it in the first day.

## Fixed

- **The Help pane (F1) is a page you can use.** It looked like a search box but
  didn't take any typing, and its own boxes covered its text. Now:
  - a real **search box** at the top: type any word and its page appears as you
    type, with suggestions (Up, Down, Enter); F1 fills it with the word under the caret;
  - **one page that scrolls**: what it is, the syntax as code with
    **Insert into the code**, what it does, and for a component its
    **Properties, Methods and Events** as links;
  - **your own names**: F1 on a variable of your program shows its declaration,
    where it's declared (a link that jumps there), how often it's used,
    **Find References**, and the help of its type below;
  - a **start page** when there's no word, and "No entry for X" with the
    closest names when nothing knows it.
- **The Search tab's results have room**: taller, readable rows.
- **A colour of a sub-object gets its swatch and colour editor**:
  `Font.Color = &H800000` now shows its colour, like `Color = …`.
- **Every pane tab has its icon**: the Assistant and Help had none.
- **Help > About shows the real version** (it said 2.117.0).

## Added

- `REdit.Placeholder`: the grey hint in an empty text box.
- `examples/windows/midi_sysex_out.rr`: send a MIDI System Exclusive message
  with Windows' winmm, every call's result in plain words, `SIZEOF` of a TYPE
  passed straight to the DLL calls (for the RapidQ group's MIDI question).
