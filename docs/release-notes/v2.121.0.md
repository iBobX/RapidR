# RapidR 2.121.0 — Preview 4: Studio, solid

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

RapidR is a modern BASIC with its own IDE, RapidR Studio. Write a program once
and run it as a **native** executable, a standalone **interpreted** app, or on
the **web**, on Windows, macOS and Linux alike.

## What's new: Studio, solid

This Preview is about **RapidR Studio** itself: finding things, seeing your
values, a debugger you can change things in, and an assistant that keeps
your chats and shows what it's doing.

### Find anything
- **Search you can see.** A Search tab with a magnifier, right next to
  Project (Ctrl+Shift+F). Search this file, the open files, the modules, the
  forms, the resources, the whole project or any folder. Results come grouped
  by file, with the file's icon, its folder and a count, and each line shows
  where it is with the match highlighted. Replace All is one undo per file.
- **Find References and Go to Definition** across the whole project
  (Shift+F12, F12, and the code's right-click menu), from the compiler's own
  understanding of your program, not a text search. Back and Forward take you
  where you were.
- **Problems that tell the truth.** An included file is checked as part of
  its project, never alone, so it shows no false errors. Errors come first,
  grouped by file. A project now says where it runs (**Project Options >
  Targets**: desktop, web or both), and web-only advice appears only when it
  matters: once per component, with a count, not once per line.

### The code shows its values
- **Helpers.** Colours show a swatch, pictures a thumbnail (a red mark when
  the file is missing), fonts a sample, choices their list. Click one, or
  press Ctrl+. on a value, and an editor opens right beside it. It writes
  back in your own style as one undo step. Argument names appear before a
  call's values (hold Ctrl to see them all), and the caret's line gets a
  one-line note. Settings > Code helpers: Off, Quiet, Helpful or Everything.
- **Values while paused,** right in the code next to each variable.

### A debugger that looks as good as it works
- Variables, Watch, Breakpoints, Call Stack and the datatips show values as
  what they are: kind icons, colour swatches with their names, constants by
  name, and a mark on what just changed.
- **Change values while paused.** Press F2 or double-click a value. Studio
  checks it before it reaches your program and says plainly when it doesn't
  fit ("count holds a whole number, and abc isn't one"). Constants come as a
  menu, long text gets its own window, and Ctrl+Z puts the old value back.
- **An editing layout and a debugging layout.** While you edit, Output,
  Build and Problems get the full width. While you debug, the debug panes
  appear beside them, then go away when you're done.

### RAI keeps your chats, and shows what it's doing
- **Chats are kept** per project, across restarts. Open, rename, search,
  delete (with Undo). They stay on your computer, never in the project.
- **A live status line**: *Thinking · Reading sites.rr · Searching the
  manual · Writing server.rr*, with the seconds beside Stop.
- **Edit a question you sent, Retry an answer,** and `/` commands
  (`/compact /new /chats /model /effort /undo /help`), with a meter for how
  much the next question sends.
- **Set Up RAI**, a two-step wizard: free on this computer (it finds Ollama,
  LM Studio and MLX Serve), or a cloud key with what it costs and what it
  sends, in plain words.
- **Reasoning effort** (Low, Medium, High) where the provider has it, with
  the model's thought one click away.
- **Small local models work again,** with a lighter set of instructions and
  tools when the model's memory is small.
- **It knows RapidR better:** a generated language card, a project outline
  and a search of this manual, so it guesses less.
- **Always in your language.**

### Studio, everywhere else
- **Forms come from your code,** several in one file, each in the designer.
- **File > Open Recent,** and Studio reopens your last project and its tabs.
- **Programs run from Studio get your Terminal's PATH** on macOS and Linux.
- **Splitters you can see and grab,** with every pane's edge drawn all the
  way down in every look, and splitters you can move from the keyboard.
- **Accessibility:** menus are in the screen reader's tree; labels can be
  links you reach with Tab; Output, Build and Problems wrap long lines.
- **The web Studio** opens a project you pick as its `.rrproj` by offering
  its folder, so every file comes along.
- **Small things made solid:** Go to Line, undo back to the saved text,
  debug panes that say *Running…* while your program runs, RGB colours and
  pictures in the designer, Chinese, Japanese and Korean text measured right,
  trees that scroll to their last row, roomier status bars, ⌘C in Variables.

### For your programs
- **RHttpServer:** a small web server for your programs, on this computer
  only. It needs a token for anything beyond reading, and refuses other
  websites by itself. It can also stream live updates.
- **RSecrets:** your program's passwords and tokens in the system's keychain,
  kept per program.
- **Encrypted MySQL and MariaDB** connections, background queries, a grid
  for millions of rows, an SQL editor, and `InTransaction`.
- **A message box's safe answer on Enter** (`MESSAGEDLG(…, mrNo)`).
- **`Application.Announce`** for screen readers, **SQL colours** in
  Markdown views, **programs' own SVG icons**, `END n` exit codes,
  `OnMessage`, `TR$`/`TRN$` for programs in every language, and RapidQ's
  standard constants built into RapidR programs.

### RapidQ, exactly
Checked against RapidQ's own compiler: a FUNCTION's `Result`, `True` in
`.bas` programs, INSTR with a start that isn't whole, FILEEXISTS with
wildcards, and a parameter named like a keyword (`Open`, `Close`, `Print`…)
no longer empties your program's strings.

### Security and legal
- **A security audit** of everything new in this Preview, with a public
  report: `docs/security/audit-preview4.md`. No critical or high findings.
  The medium and low ones are fixed: programs can't read Studio's AI keys,
  secrets are kept per program, RAI's tools stay inside the project, and
  AI keys are never sent on to a redirect.
- `cargo deny` and `cargo audit` are clean, the parsers are fuzz-tested, and
  a secret scan guards the source tree.
- **Please rebuild apps made with 2.118–2.120.** Those versions contained a
  diff routine derived from GNU diff (GPL). RapidR's diff is now its own,
  written from the published algorithm. Those versions' downloads are
  removed; their notes stay. Details: `docs/legal/review-2026-10-22-gpl-diff.md`.
