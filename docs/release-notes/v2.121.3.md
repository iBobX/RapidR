# RapidR 2.121.3 — Project properties, and two RAI fixes

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

RapidR is a modern BASIC with its own IDE, RapidR Studio. Write a program once
and run it as a **native** executable, a standalone **interpreted** app, or on
the **web**, on Windows, macOS and Linux alike. Everything in
[2.121.2](https://github.com/iBobX/RapidR/releases/tag/v2.121.2) is here.

## New: Project properties

Select your project's name at the top of the Project pane, and the Properties
pane shows the project:

- **Theme:** RapidR (follows the system), RapidR Light, RapidR Dark, RapidR
  High Contrast or Classic. The designer redraws your form in that look at
  once, whatever look Studio itself uses, and the program's `$THEME` line is
  written for you (one Undo puts it back).
- **Name, Main file, Targets** (desktop, web), **Arguments** for Run, and the
  designer's **Grid, Snap and Guides**.

Works the same in the web Studio.

## Fixed

- **Applying RAI's changes no longer closes Studio** when they add files in a
  folder your project doesn't have yet (for example icons in a new `icons`
  folder): the folder is made first.
- **Long chats with RAI are summarised at 70% of the model's window**, as
  2.121.2 promised: they were still summarised at 40,000 tokens, even on
  models with a much larger window.

## Check your download

`SHA256SUMS` lists every file's checksum, and `SHA256SUMS.minisig` is its
signature (minisign, public key
`RWT4oRaArdWhjGXn5bIqoxGsqPvaLFJxHRpQqZXKUFDFuDZWgMPC3srG`):
`minisign -Vm SHA256SUMS -P <key>`. The downloads are not code-signed yet, so
Windows and macOS ask you to confirm the first time (the README shows how).
