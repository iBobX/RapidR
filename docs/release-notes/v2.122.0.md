# RapidR 2.122.0 — Preview 5: Pair with AI

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

RapidR is a modern BASIC with its own IDE, RapidR Studio. Write a program once
and run it as a **native** executable, a standalone **interpreted** app, or on
the **web**, on Windows, macOS and Linux alike. Programs written for RapidQ
run too. Everything in
[2.121.3](https://github.com/iBobX/RapidR/releases/tag/v2.121.3) is here.

## What's new: Pair with AI

Working with an AI should make you better, and should never cost you your work.
This Preview is about both.

### RAI that teaches: Coach mode
- **A Build / Coach dial** under the model in RAI's pane. **Build** is as before:
  RAI writes the change, you review it and apply it. **Coach** gives **one hint
  at a time**: a nudge (a question, no code), then the idea (a tiny example
  about something else), then the shape of the code (blanks to fill), and the
  code itself only if you ask a fourth time. *Hint 2 of 4*, **Next Hint**,
  **I Got It**.
- **Help With This Error:** a program that won't compile, or stops at a
  run-time error, gets what the message means and why it happens on that line,
  with a hint to fix it yourself.
- **In Coach, RAI can't change your files** — not by choice of the model,
  but because Studio never offers it those tools. It can still read, check,
  search the manual and look at your running program (with your permission).

### A teacher's School Lock
- **Tools > School Lock…** turns RapidR Studio's AI off behind a password: RAI,
  and AI apps connected to Studio. Off by default. A teacher can also **keep RAI
  in Coach mode**, so students get hints and never answers.
- The password is never kept, only a salted, slow hash. Five wrong tries wait a
  minute. A school's IT can set a policy file only an administrator can write,
  and it wins over everything. [For teachers](https://github.com/iBobX/RapidR/blob/v2.122.0/docs/manual/for-teachers.md)

### AI on your own computer, made easy
- **Set Up RAI › Free, on this computer** lists the AI models **already on your
  computer** (it asks the local AI apps on this machine, nothing else), says for
  each whether it **fits your memory**, and, if you ask, **tries it**: how fast
  it answers, whether it can use tools, and whether it can build a small app
  through RAI. Then it says the **best match for your computer** in a sentence.
  RapidR never suggests a model you don't have, and downloads and starts
  nothing.
- **Small models do better with RapidR**: friendlier hints under the compiler's
  messages for habits from other languages, a recipe to start from when a model
  goes in circles, and the same advice for AI apps that connect to Studio.
- **`RSystemInfo`** for your programs: the system, the processor, the memory,
  the graphics, the battery.

### Studio never loses your work
- **Versions**, RapidR's own, in plain words (View > Versions): **Save a
  Version…** (Ctrl+Shift+V) with a check for keys and passwords before it saves,
  **What Changed?** (each file before and after, the changed words marked),
  **Go Back** (it saves a new version, the newer ones stay) and **Undo**, which
  takes back the last action and refuses when it would overwrite newer work,
  and marks in the editor's margin for what you changed since the last version. Every save is also kept in a **local history**,
  with or without versions.
- **Files that change outside Studio** (another editor, another AI agent, a
  checkout) are noticed when Studio comes to the front: a quiet reload when you
  have nothing unsaved, and a question — Compare, Use Disk Version, Keep Mine —
  when you do. Save never overwrites newer content without asking.
- **Unsaved work survives a crash**, and **RapidR writes its own crash and hang
  reports**: readable (what happened, where your program was — file, line, SUB,
  event), written on your computer, kept 30 days, never sent anywhere. Studio's
  next start offers to view, copy or save the report, or to prefill a GitHub
  issue — you decide.
- **A program no longer crashes when its events keep running inside each other.**

### RapidR in Spanish
- **Studio's whole interface**, **the compiler's messages and hints**, **the
  reference** (every component, property, method, event, statement and
  keyword) **and the manual** are in Spanish, español neutro. Pick it in
  Tools > Settings > General > Language, and RAI answers in your language too.
  The plumbing takes any language: Portuguese and Chinese are next.

### A calmer, clearer Studio
- **The Properties pane groups by what a property is for** — Appearance,
  Behavior, Layout, Font, Accessibility… — the same headings for every component.
- **Every tab strip has icons**, and shows only the icons when it is too narrow
  for the names. Dialogs, Settings among them, fit a small screen: their content
  scrolls, OK and Cancel stay in view. One design guide for all of it.
- **A calmer RAI pane, a tidier Versions pane**, and nothing cut off in any
  width, light, dark or high contrast, in English or Spanish.

### For your programs
- **`RAudioOut`**: sound made sample by sample, as your program makes it — a
  synthesizer, an emulator's beeper, a tone for a lesson.
- **Whole pictures from data, fast**: `SetPixels`, `GetPixels` and a scaling
  `StretchDraw` — a 256 × 192 picture drawn twice as large in about a tenth of a
  millisecond, so an emulator or a filter keeps 50 frames a second.
- **`RArchive`** opens zip, 7z, tar, gz, xz and zst safely (zip bombs and
  `..` paths are refused), plus `COMPRESS$` and `DECOMPRESS$`.
- **Eyes and hands for AI**: `RWindowCapture` and `RAppHands`, and the
  program Studio runs can be seen and used by RAI and AI apps — never the
  screen.
- **`Application.OnError`**, faster strings and file streams, and many fixes:
  MIDI is heard on a Mac, `RUpDown` changes what you see, Chinese text in files
  and on canvases, `FORMAT$`, one-line `IF … ELSE`.

### Security
- **The GUI test hooks no longer turn on by themselves in a released build**: they
  need a signed token (SEC-24 of the Preview 4 audit). Nothing changes for you.
- **School Lock keeps no password**: its slow hash is built on code already in
  RapidR, so it needed no new library.
- `cargo deny` (advisories, licences, bans, sources) and `cargo audit` are clean
  for this build, and the software bill of materials lists 687 components.

| **Linux** (x86_64, aarch64) | `rapidr-2.122.0-linux-<arch>.tar.gz`, `rapidr_2.122.0_<arch>.deb` | `rapidr-runtime-2.122.0-linux-<arch>.tar.gz`, `rapidr-runtime_2.122.0_<arch>.deb` |
| **Web** | `rapidr-web-2.122.0.zip`: Studio for any static web host | |
| **VS Code** | `rapidr-2.122.0.vsix` | |

Start working right away: install, open **RapidR Studio**, press Run. The SDK
includes the runtime.

**Unsigned downloads:** this release is not code-signed yet. On macOS, the
first time, "RapidR Studio" Not Opened appears: click Done, then System
Settings > Privacy & Security > Open Anyway. On Windows, SmartScreen says
"Windows protected your PC": choose More info > Run anyway. The manual's
"Getting started" has screenshots of each step.

## Known issues

- **Spanish is a first pass**: 80 of Studio's texts and 1 compiler message are
  marked for review. Tell us what reads wrong.
- **Versions:** sharing with GitHub (publish, clone, sync), experiments and
  blame come in Preview 6. The web Studio keeps the local history, not versions.
- **Crash reports** don't cover the web yet, nor a stack overflow on Windows
  (a panic is reported there), nor apps you build.
- **Coach** is the first part of RAI's teaching dial (Pair and Quiz me are next).
  A small local model follows the hint ladder loosely: Studio keeps the ladder,
  the model writes the words.
- **Not code-signed** (see above).
