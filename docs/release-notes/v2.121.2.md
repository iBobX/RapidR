# RapidR 2.121.2 — RAI finishes the job, and shows its work

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

RapidR is a modern BASIC with its own IDE, RapidR Studio. Write a program once
and run it as a **native** executable, a standalone **interpreted** app, or on
the **web**, on Windows, macOS and Linux alike. Everything in
[2.121.0, "Preview 4: Studio, solid"](https://github.com/iBobX/RapidR/releases/tag/v2.121.0)
and [2.121.1](https://github.com/iBobX/RapidR/releases/tag/v2.121.1) is here.
This release comes from building real apps with RAI, Studio's AI assistant:
it used to stop half-way and keep you waiting with only a seconds counter. Not any more.

## RAI finishes the job

- **Longer answers.** With a cloud model RAI now asks for up to 32,000 tokens
  per answer (within what the model allows), not a fixed 8,192, so a whole
  program fits. If a model allows less, RAI reads its limit from the refusal
  and asks again.
- **It goes on by itself.** When an answer reaches its length limit, RAI
  continues the same task (up to 4 more parts), asked to work in smaller
  steps. You see one calm line: *Answer was long: continuing (part 2)*. A
  change that was cut off half-way is never applied. If it finally stops, it
  says why and offers **Continue in smaller steps**.
- **Summaries keep your request.** The chat is summarised only at 70% of the
  model's window (not a fixed 40,000 tokens), and your request is kept word
  for word next to the summary, so no part of a long request is lost.

## RAI shows its work

- **A live strip while it works**, where the answer will appear: three small,
  calm dots, what RAI is doing now in words (*Reading the help of RListBox…*,
  *Looking at the form…*, *Writing main.rr (+318 lines)…*, *Checking
  (compiling)…*, *Fixing 2 problems…*), the steps already done above it with
  a ✓, the seconds, and this answer's tokens as they come in. After 10 seconds
  with nothing new it says it's waiting for the model's answer: never a silent wait.
  With reduced motion the dots stay still; a screen reader hears each new step once.
- **After the answer, its steps fold into one line** (*✓ 6 steps · show*).
- **Cards that read at a glance:** *✓ Proposed a change to main.rr  +11 −0
  Review*, the counts in green and red (readable in every theme, the + and −
  kept so colour is never alone).
- **A smart chat:** RapidR code in RAI's answers is coloured like the editor;
  hover a keyword, component or function for its quick help, click it to open
  it in the Help pane; code blocks have **Copy** and **Insert**.
- **Settings say what happens:** Settings > AI shows the longest answer
  (32,000 tokens by default) and says in plain words that a longer one goes on
  by itself and when the chat is summarised.

## Added for your programs

- `Application.ReducedMotion`: whether the user asked the system for less
  motion (macOS, Windows, the browser); RapidR's own animations follow it too.
- `AccessibleHidden` on any component (decoration a screen reader skips), and
  `RMarkdownView.CodeLanguage` with `OnCodeClick` (coloured code you can click).

## Fixed

- **Web Studio: running a program no longer stops with "RapidR panicked"
  messages.** When a program ended, or you pressed Stop, the page answered
  Studio while Studio was still busy with that run; after that the page could
  stay frozen. Now everything waits its turn, in order, nothing dropped.
- **RAI:** an accent or a "…" in the middle of a change being written no
  longer stops Studio.

## Windows 7 / 8 (32-bit)

- **DLL calls work in the 32-bit build:** each argument is passed at its own
  size (LONG and pointers 4 bytes, SINGLE 4, DOUBLE 8). Before, the first DLL
  call with arguments could crash (found with the MIDI SysEx example).
- `examples/windows/midi_sysex_out.rr` works in a 32-bit program too.

A new **Windows 7, 8 and 8.1 (32-bit) alpha** with these fixes is a separate
download: RapidR 2.121.2 for Windows 7 — Alpha 3.
