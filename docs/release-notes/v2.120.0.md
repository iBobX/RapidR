# RapidR 2.120.0 — Preview 3: RAI

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

RapidR is a modern BASIC with its own IDE, RapidR Studio. Write a program once
and run it as a **native** executable, a standalone **interpreted** app, or on
the **web**, on Windows, macOS and Linux alike.

## What's new: describe it, and RAI builds it

This Preview is about **RAI**, the assistant inside RapidR Studio.

- **Say what you want, and it opens in Studio.** "Build me a scientific
  calculator that also graphs functions." "An Excel-like app that loads a CSV
  and plots every numeric column." RAI writes the program, checks it with
  RapidR's own compiler, fixes its errors, and the new project **opens by
  itself** with the form in the designer. A banner says what happened:
  **▶ Run It**, **↺ Undo** (removes only what it made), **What Did It Do?**
- **You see the code it wrote, and learn from it.** It's plain, commented
  RapidR BASIC, right in the editor. Read it, change it, make it yours.
- **It tells the truth.** The chat shows cards written by Studio, not by the
  model: which example it started from, what it created, whether it
  compiles, what it changed (+/− with Review). If a model *claims* a change
  it didn't make, Studio notices, asks it to actually do it, and folds the
  claim away. If the program still has errors, the banner says so and offers
  **Ask It to Fix**.
- **It looks things up instead of guessing.** It reads RapidR's registry for
  the real properties, methods and events; `check_code` names a property a
  component doesn't have ("RListBox has no property ColumnWidths — did you
  mean ColCount?") and the habits of other languages, with the fix.
- **Ten working recipes** (calculator, tip calculator, stopwatch, to-do list,
  unit converter, quiz, drawing pad, password generator, CSV viewer, a list
  with Start/Stop), each with a click test. Studio hands the closest one to
  the model as a starting point, and they're in **Open an Example** for you.
- **Your choice of model.** Anthropic (Claude), OpenAI, DeepSeek, or a model
  on your own computer (any OpenAI-compatible server). Cloud models build
  complete apps; small local models (4B–9B) handle simple ones, free and
  offline: Studio sizes every request to the model's window, keeps long
  chats within it, and shows the real token counts.
- **Accessible from the first second:** focus goes to the result, the screen
  reader announces it, a live progress checklist ("✓ Looked up RCanvas · ✓
  Checked · … Working") shows what it's doing, everything works by keyboard.
- **You stay in charge:** it writes only inside your project or a new
  project folder, never runs anything (only you press Run), and **Ask before
  the assistant creates or changes files** in Settings keeps a review step
  for teachers and cautious users. It's **off until you turn it on**.

[The assistant's chapter in the manual](https://github.com/iBobX/RapidR/blob/main/docs/manual/ai-assistant.md).

## Also in this Preview

- **Windows messages reach a form's `WndProc`** on Windows: the system's
  messages and the ones a program or driver sends (MIDI input with
  `CALLBACK_WINDOW` → `MM_MIM_DATA`, `PostMessage` with `WM_USER`…), in
  interpreted and native builds. New examples in `examples/windows/`: a live
  message list, PostMessage, and MIDI input.
- **`UNLOADLIBRARY`** frees a DLL your program declared (Windows); a no-op
  elsewhere.
- **Lists scroll to what you pick:** setting `ItemIndex` brings the item into
  view; `TopIndex` makes it the first row.
- Card links and the banner work by keyboard; web Studio's Undo stays undone
  after a reload; better example matching; many smaller fixes.

The full list: [CHANGELOG.md](https://github.com/iBobX/RapidR/blob/main/CHANGELOG.md).
