# RapidR 2.122.1 — Preview 5, fixed

> **This is a Preview.** Try it and tell us what works, what breaks and what you need — [GitHub Issues](https://github.com/iBobX/RapidR/issues) for bugs, [Discussions](https://github.com/iBobX/RapidR/discussions) for questions and ideas.

Everything in [2.122.0 (Preview 5: Pair with AI)](https://github.com/iBobX/RapidR/releases/tag/v2.122.0) is here, with the fixes found in its first hours, and a first download for old PCs. If you installed 2.122.0, install this one over it.

## Fixed

- **Native builds of a program that uses RArchive work again.** With 2.122.0, `rapidr build` (and Run > Build in Studio) stopped with "file not found for module `tests`" for any program using `RArchive`, `COMPRESS$` or `DECOMPRESS$`: the installers left a piece of the zstd library out. Every release now builds such a program natively from the installed RapidR before it ships.
- **RapidR Studio in the browser no longer stops when the mouse moves over the Output pane.**
- **A build never packs a file your program writes.** Your settings, progress, a log, the paths you chose: a file the program saves is left out of the app, desktop and web, and the build says so. Before, your own copy of it went into the app you shared.
- **A web build packs only the files your program names.** Before, every `.txt`, `.csv`, `.db`, picture and sound beside the program went into the web app, named or not.
- Studio in the browser no longer asks the site for a file at every start (an error line in the browser's console).
- Native builds of a program that writes variables to a file with `PRINT #` (and uses them again) work again.
- On Windows, a missing data file now says "there is no file …", as on macOS and Linux.
- **New: `INT64` and `UINT64`.** Whole numbers beyond 32 bits, signed (to 9223372036854775807) and unsigned (to 18446744073709551615): `PRINT`, `STR$` and `HEX$` show them in full, and `\`, `MOD`, the comparisons and `AND`, `OR`, `XOR`, `SHL`, `SHR` use all 64 bits, the same in Studio, native builds and the web. Every other number works as before. See the manual's [Variables and types](https://github.com/iBobX/RapidR/blob/main/docs/manual/language.md#variables-and-types) and the example `examples/basics/int64_uint64.rr`.

## New: RapidR for old PCs (alpha)

**`RapidR-2.122.1-win7-x86-alpha1.zip`**: RapidR Studio and interpreted programs for **Windows 7, 8 and 8.1, 32-bit**. Unzip it and run `RapidR-Studio.bat`; nothing to install. It is an **alpha**: tell us what works and what doesn't on your PC (the README-ALPHA.txt inside says how). Windows 7 and 8.1 are out of Microsoft's support; use them offline or with care.
